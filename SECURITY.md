# Security Policy

Supplier Assurance Copilot is published primarily as a portfolio and reference implementation.

Do not publish secrets, API keys, AWS credentials, private endpoints, supplier documents,
proprietary policies, model traces, or generated review outputs containing sensitive information
in issues, pull requests, forks, screenshots, logs, fixtures, or configuration files. Use
`.env.example` only as a credential-free template and keep real values in ignored local files or a
dedicated secret manager.

If you find a security issue, use the repository's private **Report a vulnerability** flow under
GitHub Security Advisories. Do not open a public issue containing exploit details, credentials,
private endpoints, or sensitive supplier data.
